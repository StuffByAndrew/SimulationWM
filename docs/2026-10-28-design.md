# sim2sim design — 2026-10-28

## Goal
Evaluate a sandboxed agent's ability to reconstruct an object environment from a predefined camera and permitted interactions. The researcher owns privileged ground truth, hidden evaluation, configuration, and recordings. Keep the repository minimal and environment authoring easy.

## Accepted design
- Python/MuJoCo core; reconstructed projects contain MJCF and assets representing the reset state.
- Versioned JSON request/response protocol; bring-your-own agent and harness in a rootless OCI container, with a scripted example and client.
- Actions: observe, grasp a camera pixel, move the grasp by world displacement, release, reset, submit. Only one grasp exists at once.
- Ideal point attachment transmits force without a direct torque constraint. No jaw size, robot arm, workspace limit, or force cap. Configurable numerical softness; replaceable grasp implementation later.
- RGB, depth, and camera calibration disclosure independently configurable. Default RGB and calibration; camera remains fixed.
- Simulation advances only for action ticks. Cumulative ticks and active wall time survive reset. Hidden evaluation pauses agent wall-time accounting. Future budgets remain extensible; broker tokens can be counted when available.
- No agent network, credentials, host files, or privileged state. Optional host inference broker forwards to one configured endpoint. Fail closed without the required container isolation.
- Explicit submissions create immutable snapshots. Validate bounded asset bundles and reject traversal, plugins, and external references. Load untrusted models in isolated resource-limited workers.
- Score reset appearance and time-aligned held-out interaction rollouts, independently of the live simulation. Report RGB/depth/silhouette discrepancies and explicit probe failures. Optional privileged parameter metrics use declared correspondence, including surface sliding-friction coefficient. Scores remain researcher-only; agent sees validation results.
- Surface friction can be inferred through dragging/release motion despite an ideal attachment. Behavioral equivalence does not imply uniquely identified parameters; distinguish material coefficients from effective MuJoCo contact friction.
- Starter environments: block on table and spring/damped hinged object. New environments need scene XML and a short TOML manifest; bespoke metrics may use trusted hooks.
- Log run configuration, events, budgets, submission snapshots, metrics, private probe artifacts, and interaction video sampled in simulation time. Split videos at resets and retain partial results on failure.

## Validation and delivery
Test interactions, observations, reset determinism, budgets, malformed requests/submissions, fidelity perturbations, and complete scripted runs. Verify isolation and playable videos on a compatible container host. Runtime access is unavailable in the initial session; disclose checks that cannot run. Keep setup, protocol, authoring, and development continuity docs. Make logical git commits for completed milestones.
