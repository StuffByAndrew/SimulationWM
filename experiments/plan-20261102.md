# Experiment plan (2026-11-02, overseer draft)

All runs: strict OCI sandbox (Slurm-step enforced limits, no network, no repo/source
access), new tool-using in-container harness, exactly `gpt-6-astra`, medium reasoning,
4-hour wall limit including init/inference/eval, 2 runs per Slurm `test` job
(QoS = 5 jobs/user). Earlier development-mode runs are NOT comparable controls:
different harness and no filesystem boundary. Leak audit (experiments/validation/leak-audit-20261102.md):
blind colors were approximate guesses, no source read found; exact round-value matches are weak
evidence, so blind runs use non-round canary colors.

## Gate 0 — infrastructure (in progress)
1. Slurm-step enforced sandbox + host-side limit verification + image archive.
2. Tool-using harness + gateway broker (cost cap, exact-model/no-fallback check).
3. Leak audit of dev-mode blind runs.
4. Seeded color perturbation: random canary colors, uniform gray (pose/physics jitter deferred with replicates).
5. One 20-minute end-to-end smoke run (blocks) before wave 1.

## Anti-early-finish (all conditions, identical text)
Dev runs used 19–38% of their wall budget. Task text for every wave config:
"Reconstruct the observed scene and its physical behavior as a self-contained MuJoCo
scene.xml project, using the permitted observations and interactions. This session lasts
the full time budget and finishing early earns nothing. Hidden tests evaluate your
submissions from unobserved viewpoints and under interactions you have not tried, so
keep running discriminating comparison experiments in both worlds, refine, and resubmit
whenever your reconstruction improves. Call finish only when little time remains."
Harness: prompt says the same thing; the first early `finish` (>max(15 min, 10%) left)
is intercepted with the remaining time and a request to list unvalidated aspects, and
logged; remaining time is shown in every tool result. Metric: fraction of budget used.

## Continuation rule (user, 2026-11-03)
At 4 h, a run whose metric history lacks enough evaluated checkpoints to show a clear
trend, or whose contrast with its partner is unclear, is continued to 6 h. The
continuation is a new linked run (2 h) seeded from its last submission and its public
progress notes (`[continuation]`, strict mode).

## Budget
The user's $500 limit is read as per day (US Eastern). Wave 1 uses pool `sim2sim-500`
(2026-11-02). Wave 2 uses `sim2sim-20261103`. Continuations of wave-1 runs on 11-03
also draw from the 11-03 pool, so wave 2 may be trimmed to fit.

## Design suggestions
- Leak canaries in every blind condition (random colors/sizes no prior can match).
- Report each metric relative to trivial baselines (empty/default-cube scene, and the
  source itself as the floor) so environments are comparable.
- Replicates with seeded pose/physics perturbation: deferred by user until later.
- Pre-register hypothesis + primary metric per contrast before launch (this file).
- Fixed harness/prompt hash across conditions; only the declared factor differs.
- Track cost/tokens and time-to-first-submit; score best and final submission separately.
